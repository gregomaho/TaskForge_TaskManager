# TaskForge Project Manager

## Project Overview

TaskForge Project Manager is a C++ console-based project management application. The program allows a user to manage projects, organize project phases, create tasks, assign tasks to team members, update task status, remove tasks, and view all project information through an interactive menu system.

This project was created as a final programming project to demonstrate object-oriented programming concepts, multiple classes, collections, enumerations, modular programming, and user interaction through a console UI.

---

## Purpose

The purpose of this program is to help users organize a project by breaking it into smaller parts:

- Projects
- Project phases
- Tasks
- Team members

The project manager gives the user a high-level view of the project, while the task manager handles individual tasks. The team member manager keeps track of users who can be assigned to tasks.

---

## Program Features

The program currently supports:

- Creating projects
- Creating phases inside projects
- Moving tasks into project phases
- Creating tasks
- Assigning tasks to team members by ID
- Updating task status
- Removing tasks
- Adding team members
- Removing team members
- Displaying all projects, tasks, and team members
- Interactive console menu interface
